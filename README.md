# Imaging_Projects
This repository showcases a selection of projects completed during the first year of my Master's of Biomedical Engineering at SJTU.

## 1. 2D-CT reconstruction 
This project consists of the reconstruction of 2D Computed Tomography images. 

We provide the Jupyter Notebook (1-CT-sinogram-FBP.ipynb), as well as the data used during the project (CTSlice-1/2/3.png) and the project report (CT_Scan.pdf).

## 2. Pivot Calibration 
This project consists of the obtention of a tracker tip's position through the use of pivot calibration.

We provide the Jupyter Notebook containing code (Pivot_Calibration.ipynb), as well as the data used to obtain tracker tip's position (Tpointer2Cam.txt) and the project report (Pivot_Calibration.pdf). 

## 3. Marching Cubes for Surface Extraction and Rendering
This project consists of the extraction and rendering of a 3D surface using the Marching Cubes algorithm. 

Its purpose is to visualize a hip bone, using a 3D tensor containing bone density data. The data is not provided in this repository. 

We provide the MATLAB functions (launch.m and recursive_marching_cubes.m) as well as the project report. 

## 4. Statistical Shape Modeling of the Femur
This project consists of determining a statistical shape model (SSM) for the femur bone. Its purpose is to understand the variability of the femur bone's shape among patients. 

For this project, I used 20 point clouds, each one representing a patient's femur. The data is not provided in this repository. 

We provide the Jupyter Notebook (SSM_Notebook.ipynb), as well as the raw Python code (statistical_shape_modeling.py) and the project report (Statistical-Shape-Modeling-Femur.pdf).
